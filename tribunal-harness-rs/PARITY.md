# PARITY.md — behaviour contract between the TypeScript app and the Rust port

One row per feature (from the README list) and per route. The **Verified**
column is filled only with evidence produced in this repository (a named test,
a fixture diff, or a captured server response). Status values:
`verified`, `[partial]` (what differs and why), `[blocked]` (what could not be
checked and why).

All tests below are hermetic (`cargo test --workspace`, 96 tests, no network,
no API key). Test names are `crate/tests/file.rs::function`. The fixtures were
recorded from the TypeScript app on 2026-09-23 (`fixtures/README.md`).

  "max_tokens"` → truncation error) are unit-tested with a scripted transport

  host is unreachable from the sandbox. **[blocked]**

  one by construction; not exercised against the service. **[blocked]**
